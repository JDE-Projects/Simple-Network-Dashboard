Set up certificate trust

This one-time Windows step lets your browser verify this dashboard's local HTTPS certificate.

A browser warning is expected right now. Do not treat this page or its download as trusted until you independently verify the certificate checksum and complete the import.

Verify first, then import

  1. Download the public root certificate. The dashboard installer printed its independent SHA-256 checksum when it finished.
    Download certificate
  2. In Windows PowerShell, run this command and compare its output with that installer checksum. Stop if they do not match.Get-FileHash -Path "$env:USERPROFILE\Downloads\caddy-root-ca.crt" -Algorithm SHA256
  3. Only after the checksums match, import the certificate into your current Windows account's trusted root store.Import-Certificate -FilePath "$env:USERPROFILE\Downloads\caddy-root-ca.crt" -CertStoreLocation Cert:\CurrentUser\Root
  4. Close and reopen the browser, then return to the dashboard.

How you'll know it worked

Nothing on this page or in the dashboard can confirm the import for you, and your browser will not announce that the certificate is "trusted." The real signal is the browser's own address bar: when you return to the dashboard, a padlock shows and the security warning is gone. If the warning is still there, the import did not take. Recheck the steps above.
